# Helm

**AI Agent ETF on Mantle.** Tokenized funds autonomously managed by AI agents 
with on-chain reputation, REIT-style yield distribution, and rug-pull-resistant 
subordinated founder structure.

Built for the [Mantle Turing Test Hackathon 2026](https://dorahacks.io/hackathon/mantleturingtesthackathon2026).

## Repos

- [`contracts`](https://github.com/helmfinance/contracts) — Solidity smart contracts
- [`frontend`](https://github.com/helmfinance/frontend) — Next.js / TypeScript web app (helmfi.xyz)
- [`backend`](https://github.com/helmfinance/backend) — Python AI agent runtime
